# 运行说明

## 1. 文件结构

```text
01-正文.md
02-说明.md
代码/
  convert.py
  feishu.js
  test_convert.py
  requirements.txt
  .env.example
  .gitignore
  sample.txt
```

`convert.py` 是入口。没有参数时进入交互模式，也支持单次命令。

## 2. 环境安装

需要 Python 3.12。打开 PowerShell，进入解压后的 `代码` 目录：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

本地文件转换无需浏览器。飞书读取还需要：

1. 安装 Node.js，使 `npx` 可用。
2. Chrome 安装并启用 Agent360 Browser MCP 扩展。
3. 在该 Chrome 中登录飞书，确认有目标文档访问权限。

扩展地址：https://chromewebstore.google.com/detail/agent360-browser-mcp/jdehgalffmffhfhmmhaokfbfnafnmgcl

程序通过 `npx -y @agent360/browser-mcp@1.31.0` 启动 MCP 服务，首次需下载 npm 包，不需要另改 AI 客户端配置。

## 3. 配置模型

`.env.example` 是配置模板，程序**不会自动加载 `.env` 文件**。程序直接读取进程环境变量：

```dotenv
LLM_BASE_URL=http://221.131.102.69:18088/v1
LLM_MODEL=glm-5.2
LLM_API_KEY=<你的 key>
```

前两项已是代码默认值。如需显式配置，在 PowerShell 执行：

```powershell
$env:LLM_BASE_URL = "http://221.131.102.69:18088/v1"
$env:LLM_MODEL = "glm-5.2"
```

密钥推荐在程序提示时隐藏输入，不写入源文件。也可通过环境变量 `LLM_API_KEY` 提供；不要把占位符当成真实密钥，不要截图密钥。

如果当前终端之前配置过其他接口，请先确认三项配置相互匹配。公司接口要求来源公网 IP 在白名单内；HTTP 不加密，密钥和正文均存在明文传输风险。

## 4. 启动与转换

```powershell
.\.venv\Scripts\python.exe convert.py
```

随后粘贴一个文件路径：

```text
文档地址或本地文件路径 > C:\Users\user\Downloads\说明.docx
```

或粘贴飞书链接：

```text
文档地址或本地文件路径 > https://你的租户.feishu.cn/docx/文档ID
```

程序先保存原始结果，随后显示目标接口、模型和发送确认。只有输入 `YES` 才会调用模型；未配置密钥时，随后提示隐藏输入。

- 本地文件按文件名保存：`output/说明.md`、`output/说明.raw.md`。
- 飞书按文档 ID 保存，不使用可能含非法字符的标题。
- 自动命名重名时追加 `-1`、`-2`，不覆盖文件。
- 最终 `.md` 在保留正文后追加「文档总结（AI 生成）」，以 1–5 条要点概括原文；总结需人工核对。
- 原始 `.raw.md` 和纯本地模式不包含 AI 总结。缺少总结或总结为空时，不保存为成功文件。
- 成功或失败后均可继续输入下一个地址；输入 `exit` 退出。

不调用模型，只做本地提取：

```powershell
.\.venv\Scripts\python.exe convert.py --local-only
```

该模式只生成 `.raw.md`，不需要 Key。飞书读取本身仍需联网。

也可单次执行：

```powershell
.\.venv\Scripts\python.exe convert.py sample.txt
.\.venv\Scripts\python.exe convert.py sample.txt -o output/demo.md --local-only
```

显式 `-o` 的输出已存在时会拒绝覆盖，需更换名称。

## 5. 自检与截图

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

当前 10 项自动测试通过，包含取消发送不调用模型、拒绝密钥占位符和错误信息不回显服务端正文的检查。模型请求单元测试使用 Mock，不代表真实服务响应。

正式截图需要真实运行默认配置：

1. 启动程序，输入 `sample.txt`。
2. 确认允许发送无敏感信息的样例并输入有效 Key。
3. 收到成功消息后，截图终端的输入、模型名及输出路径。
4. 打开生成的 `.md`，截图转换结果；检查截图中没有密钥。

当前默认 GLM-5.2 的生成请求此前超时，**本包没有提供成功截图**。服务恢复后补拍，不把模型列表接口的成功当成生成成功。发生超时时原始结果会保留，按网络、IP 白名单与推理服务状态排查。

## 6. 已知边界

- 支持本地 DOCX、PDF、PPTX、XLSX、HTML、TXT、MD；PDF 需要文字层，不做 OCR。
- 飞书只支持 `/docx/`，不支持 `/wiki/` 与在线表格。页面结构变化或动态加载可能导致遗漏，多次提取结果可能不同，需人工核对；必要时先导出 DOCX。
- 图片、附件、复杂表格、嵌入内容不保证完整；Excel 不保留公式计算语义。
- 单次最多 12000 字符，API 超时 120 秒，无自动重试；超限、空回复和截断不会伪装成成功。
- 没有自动密级识别、脱敏或加密存储。内部文档必须遵守公司授权；`.gitignore` 不能替代访问控制。
