## 二、前置：环境搭建

Python 3.8.3 + `.venv` 隔离 + 唯一依赖 `httpx`（刻意不用 openai SDK，见下）；
Node v22 与 npm 仅服务 MCP。自检脚本可输出完整环境报告。

**为什么不用 SDK**：作业目标是理解协议，手写后请求体、SSE 分帧、重试都可见；
代价是高级特性要自己补，生产项目仍推荐 SDK。

**搭建中三个坑**：

| 问题 | 原因 | 解决 |
|---|---|---|
| 中文乱码 | 控制台 GBK 与脚本强制 UTF-8 冲突，但管道又必须 UTF-8 | 按 `isatty()` 分流 |
| 点运行报「找不到路径」 | 文件 shebang 被 Code Runner 遵循，Windows 不认 `/usr/bin/env` | 删 shebang + 关 `respectShebang` |
| 引号路径执行报错 | PowerShell 需要 `&` 调用符 | `& "...\python.exe" -u demo.py` |

## 三、部分一：`demo.py` —— 调用链路调试

**定位**：调试工具，不是业务功能。用四个由浅入深的场景逐层验证链路，
出问题时能立刻定位断在哪一层。

```powershell
.\run.ps1 demo.py            # 真模型
.\run.ps1 demo.py --mock     # 离线（走同一套代码）
.\run.ps1 demo.py --only 2   # 只跑某场景
```

| 场景 | 验证目标 | 实测 |
|---|---|---|
| 1 基础对话 | 请求格式、SSE 分帧、流式拼接、token 统计 | 1.61 s |
| 2 本地工具 | Function Calling、多工具并行、结果回灌 | 2.11 s，算出 1488.77 元 |
| 3 Skill | 渐进式披露、强制输出格式 | 7.94 s，5 条 JSON 审查意见 |
| 4 MCP | 跨进程协议、工具发现、与本地工具混用 | 3.88 s，14 个工具 |

**三个关键实现**

1. **流式 `tool_calls` 增量拼装**：参数按 `index` 分片到达，需分别累积 `id/name/arguments`。
   踩过的坑是累积结果是扁平槽位、下游期望包装格式，导致工具名为空、循环跑满。
   用 `mock_llm.py` 把一次调用拆 4 片下发才能稳定复现。

2. **Skill 渐进式披露**：平时只暴露 `name + description`（几十个 Skill 也就几百 token），
   模型判断需要时才加载正文。实测模型自己走了 `load_skill → read_file` 两步，
   并按 JSON 数组输出审查意见，还真的挑出了 `ast.Pow` 无上限的隐患。

3. **MCP 客户端**：手写 JSON-RPC over stdio，完成
   `initialize → initialized → tools/list → tools/call`。
   实测模型把本地工具与 MCP 工具混着用（`mcp_list_allowed_directories` + `list_files`
   + `mcp_read_text_file`），说明三类能力在 agent 眼里是同一等公民。

## 四、部分二：任务规划 —— 任务数据层

**定位**：业务应用。把「与我相关的任务」变成可勾选清单并算出提醒时间。
与部分一不同，**核心不在模型而在数据**——任务本身是脏的，得先让数据可靠。

```powershell
.\run.ps1 checklist.py                 # 渲染清单
.\run.ps1 checklist.py --today         # 今天要做什么（含逾期）
.\run.ps1 checklist.py --reminders     # 未来 7 天提醒计划
.\run.ps1 checklist.py --check         # 只校验数据
.\run.ps1 checklist.py --ask "先做哪件" # 交给模型判断
```

| 能力 | 说明 |
|---|---|
| 数据校验 | ID 唯一、枚举合法、日期可解析、`start ≤ due`；错误定位到 `tasks[n]（id）` |
| 四类视图 | 逾期 / 今天 / 接下来 / 已完成，桶内按「优先级 → 截止」排序 |
| 清单渲染 | 按天分组、带勾选框与剩余时间 |
| 提醒计算 | 截止前 1 天 09:00 + 当天 09:00，已过期不补发 |

**两个关键设计（都是被实测打回来的）**

1. **逾期必须按时刻算**。最初比较 `date`，结果「今天 17:00 到期」的任务在 18:37 仍被归入
   「今天」。让模型回答一次，它说「已逾期 1 小时 37 分」——模型的判断比我的代码准，
   这是必须修的信号。
2. **「现在」从参数注入**（`--at`），否则「逾期 2 天」无法复现、无法写进自检。

**实测**：样例 8 条任务零错误；9 条脏数据报出 7 个错误 + 1 个警告，逐条可修；
`--ask` 时模型只调 1 次工具，结论与数据一致，没有编造任务。
